# Compilation and Execution Guide

## Requirements

Before compiling and running the project, the following software must be installed:

- Java JDK 17 or newer
- Maven
- Python 3
- Scrapy

---

# Java / Jsoup Part

## Compile the Project

Open a terminal in the project root directory and execute:

```bash
mvn compile
To subsequently open the project execute the command
```bash
mvn exec:java
